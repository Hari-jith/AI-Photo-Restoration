# STEP 1: install PyTorch FIRST (not listed below, because the command
# differs for CPU-only and NVIDIA GPU computers). Pick ONE:
#
#   CPU only:
#     pip install torch==2.1.2 torchvision==0.16.2 --index-url https://download.pytorch.org/whl/cpu
#
#   NVIDIA GPU (CUDA 12.1):
#     pip install torch==2.1.2 torchvision==0.16.2 --index-url https://download.pytorch.org/whl/cu121
#
# STEP 2: install everything below with:
#     pip install -r requirements.txt
#
# Notes
#  * torch is used from Module 7 (device.py) and Module 9 (DDColor).
#  * torchvision is not imported by our code yet. It is installed now and
#    pinned to 0.16.x because the face-restoration and super-resolution
#    libraries added in Modules 11-12 (via basicsr) break with newer versions.
#  * DDColor has an OPTIONAL dependency on "timm" and falls back to its own
#    code when timm is missing, so timm is deliberately not installed.
#  * Packages for later modules (fastapi, uvicorn, python-multipart, pytest,
#    httpx, gfpgan, realesrgan, basicsr, facexlib) are added only when the
#    module that needs them is built.
